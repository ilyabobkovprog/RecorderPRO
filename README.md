RECORDER PRO - Захват экрана и звука для Linux

📋 Описание

Профессиональное приложение для захвата видео с экрана и звука с микрофона в Linux. Поддерживает паузу, отложенный старт и автоматическое объединение потоков.
✨ Возможности

    🎥 Захват экрана в разрешении 1920x1080

    🎤 Захват звука с выбранного микрофона или устройства по умолчанию

    ⏸️ Пауза записи (только аудио, видео продолжается)

    ⏱️ Отложенный старт с настраиваемой задержкой

    🎮 Горячие клавиши для удобного управления

    📁 Автосохранение в тематические папки

    🔄 Автоматическое объединение аудио и видео потоков
